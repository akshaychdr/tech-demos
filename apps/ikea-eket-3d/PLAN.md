# EKET manual-first assembly

## Goal
Mirror the IKEA paper manual: manual-matched cameras, context + close-up sub-steps, decluttered visibility, synced manual callouts.

## MVP
- Frame-based script (`assemblyFrames.ts` + `steps.json` `manualCamera` / `subSteps`)
- `ManualViewer`: ghost prior assembly, hide future parts, hardware insert animation, overlays
- Paginated flat-pack (panels / drawers / hardware tray)
- Capture: QA screenshots per frame + 6+ close-ups + 85s video

## Deferred
- PDF vector callout auto-detection
- AR alignment
