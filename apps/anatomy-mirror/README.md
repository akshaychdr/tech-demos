# Anatomy Mirror

A phone-first mirror that teaches the skull. The camera never leaves the device. MediaPipe places one BodyParts3D cranium and jaw on your face, with the eye sockets lined up to your eyes and an x-ray glow that feathers into the skin.

Hosted at [https://akshaychdr.github.io/tech-demos/anatomy-mirror/](https://akshaychdr.github.io/tech-demos/anatomy-mirror/).

## Run

```bash
bun install
bun run dev
```

Open `http://localhost:5177/tech-demos/anatomy-mirror/`.

```bash
bun test
bun run build
```

## What you can do

Welcome, then Explore. The skull, eyes, and outline start on; muscles, brain, and labels start off. Touch and tell, Make a face, and a five-question quiz are still there. Open Adjust for the look, the reveal, and the fit sliders. A link with `?beat=8` shows a challenge on the welcome screen.
